# Psychedelic Flower

A realistic, slowly shifting psychedelic flower drawn in real time with WebGL — one HTML file, no libraries.

**Live:** https://henseries.github.io/psychedelic-flower/

- Drag / move the mouse to move the light
- Slider (or mouse wheel) changes the trip intensity
- Pause and save-image buttons at the bottom; on desktop, Space pauses and S saves

Works on phones and desktops in any modern browser (Chrome, Firefox, Safari, Samsung Internet).
